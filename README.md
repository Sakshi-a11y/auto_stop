# AutoSafe – Vehicle Overloading Protection System

AutoSafe is an IoT-based vehicle safety solution designed to **detect vehicle overloading and help prevent unsafe vehicle operation**.

The project combines embedded hardware, IoT communication, and a web-based management system to monitor vehicle load and manage overloading violations.

## ✨ Key Features

* Real-time load monitoring
* Automatic overload detection
* Vehicle violation tracking
* IoT-enabled hardware communication
* Web-based vehicle management
* Automated vehicle status monitoring
* Digital fine/payment support
* Admin dashboard for monitoring
